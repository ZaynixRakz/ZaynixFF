# Zaynix FF — SwiftUI UI Prototype

A native SwiftUI UI prototype inspired by the dark iOS workspace layout shown in the reference screenshots.

## Included
- Home dashboard
- Target selector (UI only)
- Library
- Clean workspace screen
- Settings / device information
- License presentation screen
- Reusable cards and bottom navigation
- No game injection, patching, bypassing, or modification logic

## Requirements
- Xcode 16+
- iOS 16+

## Setup
1. Create a new Xcode project: iOS > App.
2. Product Name: `ZaynixFF`
3. Interface: SwiftUI
4. Replace the generated Swift files with the files in this folder.
5. Set deployment target to iOS 16.0 or newer.
